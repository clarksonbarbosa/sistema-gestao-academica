# Sistema de Gestão Acadêmica

## Objetivo
O Sistema de Gestão Acadêmica tem como objetivo auxiliar no gerenciamento de informações acadêmicas de uma instituição de ensino.

## Principais funcionalidades
- Cadastro de alunos;
- Cadastro de professores;
- Cadastro de turmas;
- Cadastro de disciplinas;
- Registro de notas e frequência;
- Consulta de informações acadêmicas;
- Geração de relatórios.

## Gerência de Configuração
Este projeto será utilizado para aplicar conceitos de Gerência de Configuração, controle de versões, registro de alterações e criação de versões do sistema.
